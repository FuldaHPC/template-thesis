% Declare every acronym once here, then write \ac{key} in the text.
% The first \ac{hpc} prints "High Performance Computing (HPC)" and every later one prints "HPC".
% \acs{key} always gives the short form, \acl{key} the long form, and \acp{key} the plural.
% Only acronyms that are actually used appear in the List of Acronyms, so unused declarations are harmless.
% For a German thesis, translate the long forms below.

  short = HPC,
  long  = High Performance Computing
}

  short = MPI,
  long  = Message Passing Interface
}
